## 使用方法
### 直接用 exe（推荐，不用装 Python）

到本项目 Releases 页下载最新的 `ios观星.exe`，双击即用：

- 无需安装 Python，单文件自带全部运行环境和网页版
- 生成的存档/密钥文件统一在 `%LOCALAPPDATA%\yanyu-guanxing\`，不污染桌面
- 首次运行若弹出蓝色的“已保护你的电脑”（SmartScreen），点“更多信息 → 仍要运行”即可（exe 未买代码签名证书，正常现象）
- 建议放到普通文件夹（如 `D:\ios观星\`）再双击

### iOS抓包

- 安装免费开源抓包工具 ProxyPin ，手机直接去AppStore即可安装

### 抓包流程

1. 打开proxyin，点击右下角开始，开启抓包（无需开启HTTPS代理）
2. 进入游戏主页面，（未登录请先登录，为防止丢失数据请先点击左下角[上传]），点击左下角[下载]
3. 回到proxypin，点击右下角停止，结束抓包
4. proxypin右上角三点 —— 视图导出 —— （新版本要选择HAR格式）
5. 将导出的结果传输到电脑
6. 将har文件拖动至ios.exe内并回车即可完成导入
