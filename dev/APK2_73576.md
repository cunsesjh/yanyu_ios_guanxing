# apk-2 的 73576 获取方式与移植

分析对象：`cunsesjh/apk` 的 `apk-2/default.apk`，asset ID 719294963，
403953803 字节。它是 `cn.suanbujin.app` 工具客户端，不是烟雨江湖游戏包。
公钥 DER SHA-256：`4613d6aa4f67987c1ded797d72f7e3aca9d2bc618b54adccb9419f95797071c9`。

## 静态证据

DEX 的 `P0.e(Context, byte[])`：读取 `assets/download-public.der`，生成
16 位随机字母数字密钥，用 `RSA/ECB/PKCS1Padding` 公钥加密；把
`{"stamp":0,"auto":"RSA密文base64"}` 用登录握手推导的协议密钥进行
带长度字的 XXTEA 加密，最后 Base64 编码请求体。

`P0.f(String,String)` 从账号和响应头 `k` 推导协议密钥；
`P0.g(...)` 使用已有账号、区服、session 和原平台请求头，向原游戏地址
主动发出新的 `download3`，用自己选择的随机密钥解响应 `data` 外层。
注意：这里 `auto` 位于加密前的请求 JSON 中。

`IosProxyService.lambda$5` 和 `SecureDecoder.decodeAt` 随后将解出外层的
内层存档发往 `https://tool.launch-ai.cloud/api/feilong/v1/decode`。
Android 的 `i.c(...)` 路径也使用这个远端解码接口，并有旧版请求头默认值。
因此，APK 支持获取新版存档不等于它包含了可复制的 iOS 随机数推导算法。

## 本项目实现

`yyjh/capture/retrieve.py` 重新实现公钥封装与主动下载；内层复用本项目
已有 `envelope.open_full`，只接受 zlib/JSON 解码成功且账号（如有）、
区服匹配，并含 MainRole、Roles、Rnds 的完整存档。不接入 APK 的远端服务。
仅允许原 iOS/Android 正式服域名，不跟随 HTTP 重定向，不复制无关认证头。
保留原平台版本与渠道头，没有复制 Android 路径的旧版本伪装。

在项目根目录运行（Python 3.9+）：

```sh
python -m yyjh retrieve "/path/to/fresh.har"
python -m yyjh capture "/path/to/fresh.har" --fetch --db
python -m yyjh retrieve "/path/to/fresh.har" --fetch --output fresh-save.json
python -m yyjh rebuild fresh-save.json --runtime ios --db
```

第一条完全离线。`capture --fetch` 使用原有导入/输出链路，保留 iOS 平台，
可直接生成 dat.db、JSON 和元信息；交互向导也提供主动下载选项，默认离线。
主动模式不会失败后回退到残缺角色摘要，也不把临时传输密钥记为本地存档密钥。
`retrieve --fetch` 仅保存 JSON，不覆盖已有输出文件。
主动模式会使用 HAR 中的登录会话向原游戏服务器发起一次 download3，
不会上传存档到第三方。
若提示会话失效，请从登录前开始抓包，重新进入目标角色后立刻导出 HAR 再运行。
它下载的是服务器上当时的云存档，不能恢复旧 HAR 所对应的历史状态。

## 验证边界

已进行静态调用链分析、离线握手提取、RSA 私钥反向校验、请求体检查与
会话隔离/错误响应测试。经用户明确授权，使用 iOS HAR 登录会话向原游戏
服务器发出一次只读 download3：响应成功，本地解出 DBVersion=73576、
222 个顶层字段、15 个角色的完整存档，包含 Rnds.Sds 世界种子。
未调用 APK 的远端解码服务，也未将账号、session 或存档提交至仓库。
因此已验证该样本的主动下载及本地内层解码；未恢复新版本随机传输密钥的生成算法。
未来版本若内层封装改变，本地校验会明确失败，不会使用残缺摘要代替。

既有随机传输密钥加密的 73576 HAR 仍不能因这项移植而直接离线解密。

本次离线样本结果：iOS 73570 的 222 字段完整存档通过新响应校验器；
Android 73570 旧解码仍得到含 Rnds 的 218 字段存档。
两份 iOS 73576 HAR 均能提取握手/会话候选，但原有被动完整解码仍失败。
Android 样本未选出可用主动下载会话，不能据此声称其主动下载已验证。

回归命令：`python dev/check_har_decode.py` 与 `python dev/test_retrieve.py`。
